# Fleet Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One local browser page that maps every agent session on this Mac and laptop2 as nodes in initiative clusters, with traffic lines, two ages per node, a detail rail, and peek/jump/send/close actions.

**Architecture:** A `kitty/fleetmap/` package of small standard-library modules: a tailing transcript reader, a local session registry reader, an `orca` CLI client, cluster and edge resolvers, a snapshot assembler, an action router, and an HTTP server on loopback that serves one static page and a JSON snapshot refreshed by a collector thread. A `bin/fleet-map` launcher reuses a running server. The existing nekotron hook gains a session-id keyed state file so Orca-hosted sessions get "needs you".

**Tech Stack:** Python 3 standard library only (`http.server`, `json`, `subprocess`, `threading`, `secrets`). Plain HTML, inline SVG and JavaScript, no framework. `unittest` tests run from the repo root. The `orca` CLI, `kitten`, `tmux` as subprocesses.

**Spec:** `docs/superpowers/specs/2026-10-19-fleet-map-design.md`

## Global Constraints

- Standard library only; no pip dependencies.
- Listener binds `127.0.0.1` only; every request carries the per-launch key (`?key=` or `X-Fleet-Key` header) or gets 403.
- No daemon: the server exits after 30 minutes with no page connected.
- Transcripts are tailed from a saved byte offset; never re-read whole on refresh.
- Close always confirms in the page and the server never kills by pid.
- Node ids are host-qualified: `local:sid:<sessionId>`, `local:term:<handle>`, `local:agent:<agentId>`, `env:<name>:term:<handle>`.
- Four states: `working`, `done`, `attention`, `idle`. Fleet board colors: blue `#4f8ef7`, green `#4cc38a`, orange `#f0803c`, gray `#6b7394`.
- US English in all prose, comments and test titles.
- Tests: `python3 -m unittest tests.<module> -v` from the repo root; tests import modules via `sys.path.insert(0, ROOT/'kitty')` like `tests/test_fleet_tmux.py`.

## Review Focus

- A transcript whose last line is half-written while Claude is mid-stream: the reader must keep the offset at the last complete newline and not crash. Pinned in Task 2.
- A registry pid that is alive but is no longer a Claude process (pid reuse after a crash): the session must not be drawn. Pinned in Task 3.
- `orca` absent, or laptop2 asleep so `--environment laptop2` hangs: local nodes still render and the region shows "unreachable". Pinned in Tasks 4 and 7.
- A 40 MB transcript on first open: Purpose is found by reading from the start and stopping at the first human text; recent fields come from a bounded tail. Pinned in Task 2.
- An action on a node whose terminal vanished between snapshot and click: the server returns the CLI error and the page shows it; nothing else is closed. Pinned in Task 8.

### Task 6: Traffic edges

**Files:**

**Interfaces:**
- Consumes: `TranscriptFacts.outbound/inbound` (Task 2), `LocalSession` (Task 3), Orca `inbox/workers/runs` lists (Task 4).
- Produces: `class Edge` dataclass: `src: str`, `dst: str`, `count: int`, `newest: float`, `kind: str` (`message|dispatch|subagent`).
- Produces: `class Resolver(sessions: list[LocalSession], terminals_by_host: dict[str, list[dict]], workers_by_host, runs_by_host)` with `node_for_name(name: str) -> str|None` (strips a trailing ` [ref]`, matches registry `name`, then a subagent id), `node_for_socket(uri: str) -> str|None` (`uds:/tmp/cc-socks/<pid>.sock` to the session with that pid), `node_for_handle(handle: str, host: str) -> str|None` (`dispatch:ctx` via workers' `agentTerminalHandle`, `run:` via `coordinator_handle`, bare `term_` directly; a terminal maps to `local:sid:` through `orca_pane == (tabId, leafId)`, else to `<host>:term:<handle>`).

### Task 7: Snapshot assembler

**Files:**
- Create: `kitty/fleetmap/model.py`
- Test: `tests/test_fleetmap_model.py`

**Interfaces:**
- Consumes: Tasks 2 to 6.
- Produces: `class Collector(orca: OrcaClient, config_path=CONFIG_PATH, sessions=list_local_sessions, tmux_sessions=fleet_tmux.sessions)` with `snapshot() -> dict` and persistent per-session `TranscriptFacts` and `first_seen` caches between calls.
- Snapshot JSON shape:

```json
{"generated_at": 0.0,
 "hosts": [{"name": "local", "label": "This Mac", "reachable": true},
           {"name": "laptop2", "label": "laptop2", "reachable": false, "error": "timeout"}],
 "nodes": [{"id": "local:sid:s1", "host": "local", "kind": "claude|terminal|subagent", "parent": null,
            "title": "", "purpose": "", "doing": "", "last_said": "", "state": "working",
            "you_at": null, "it_at": 0.0, "never_addressed": false,
            "cluster": "PR 6869 review", "repo": "glow-core", "worktree": "", "branch": "",
            "hosting": "orca|kitty|tmux|laptop2", "model": null, "ctx_pct": null, "cost": null,
            "moves": [[0.0, "Bash: Run gate:ratchet"]], "terminal": "term_x", "tmux": null, "kitty_window": null}],
 "edges": [{"src": "", "dst": "", "count": 1, "newest": 0.0, "kind": "message"}]}
```

- State rules, in this order: a `claude` node is `attention` or `done` when `hook_state` says so; else `working` when registry `status == "busy"`; else `idle`. A `subagent` node is `working` when its transcript mtime is under 120 s old, else `done`. A `terminal` node is `working` when `now - lastOutputAt < 60`, else `idle`.
- `never_addressed` is true when `you_at` is `None`. For a `claude` node whose terminal is a worker's `agentTerminalHandle`, `you_at` ignores the first human prompt (Decision 9).
- `hosting` is `orca` when `orca_pane` matched a terminal, `tmux` when the pid is in a `neko-*` session, `kitty` when `kitty_key` is set, else `orca` if an Orca terminal matched by cwd, else `unknown`.
- Local Orca terminals with `agentIdentity` set and no matching Claude session become `terminal` nodes; those with no `agentIdentity` are skipped.
- A host whose Orca calls raise `OrcaError` is listed with `reachable: false` and contributes no nodes; the local host is always listed.
